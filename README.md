# Quran browser studio

Phone-browser Quran card tool. Select complete ayahs, preview both ratios, review your own audio files, and record video locally. Audio rights and full review are required before export. No YouTube connection or automatic publishing. Private media are not included.

Quran text is retained verbatim from Tanzil, https://tanzil.net/download/ and https://tanzil.net/docs/text_license . Font licenses are bundled in the HTML source.
